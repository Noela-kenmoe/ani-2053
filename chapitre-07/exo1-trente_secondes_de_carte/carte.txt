Module : NKLogger

D'après le projet : 
Le module utilise les bases du moteur (pour la mémoire, les textes et les actions en parallèlle) afin de pouvoir envoyer les messages
sur plusieurs ordinateur sans avoir besoins d'afficher une fenetre ou un écran graphique tout se passe dans le terminal.

Après l'en-tête : 
Après la lecture de l'entete "include/NkCore/Logger/NKLogger.h" le module NkLogger est la classe principale du système de logging avec support multi-sonk. C'est le point d'entré central pour émettre des messages de log vers une ou plusieurs destinations configurables. Ces fonctionnalités sont  : 
-L'envoie simultané vers console, fichier, reseau
-Patterns style splog ou formatage positionnel NkFormat
-Capture automatique de fichier/ligne/fonctionnalités
- Synchronisation interne pour usage concurrent
- Control granulaire de la verbosité
